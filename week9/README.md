# MR_Lab_Report_8 — Vision-Based Target Tracking Using Camera

This lab covers vision-based perception and control on the TurtleBot3 Waffle in Gazebo simulation using ROS 2 and OpenCV. It walks through subscribing to `/camera/image_raw`, performing HSV color segmentation, computing object centroids, and implementing a proportional controller to align and approach a colored target. Exercises extend the system to blue object detection, kp tuning, odometry-tracked 360° search, and multi-color priority behaviors. All tasks and exercises are implemented as standalone ROS 2 Python nodes.
